STARTING
  Double-click:  start-servers-tmux.bat          (Basic)
  Double-click:  start-servers-tmux-tunnel.bat   (+ Cloudflare)

STOPPING
  Ctrl+C                Stop all servers (any pane)
  Close window          Same as Ctrl+C
  stop-servers.bat      Alternative shutdown script

NAVIGATION (All commands start with Ctrl+B)
  Ctrl+B  →  ←/→/↑/↓   Switch between panes
  Ctrl+B  →  z          Zoom current pane (toggle fullscreen)
  Ctrl+B  →  [          Scroll mode (q to exit)
  Ctrl+B  →  d          Detach (servers keep running)

SCROLLING LOGS
  1. Press: Ctrl+B then [
  2. Use arrow keys or Page Up/Down
  3. Press: q (to exit scroll mode)

ZOOM A PANE
  1. Navigate to pane (Ctrl+B + arrow)
  2. Press: Ctrl+B then z
  3. Press: Ctrl+B then z again (to un-zoom)

REATTACH AFTER DETACH
  wsl -e tmux attach -t chaycards-servers
  wsl -e tmux attach -t chaycards-servers-tunnel
